## 🔑 Key Concepts

| 📘 Concept | 📝 Description |
|-----------|----------------|
| **Ansible Facts** | System characteristics gathered from target systems that let playbooks adapt to different environments |
| **Fact Filtering** | Narrowing gathered facts down to the ones a playbook needs |
| **Inline Variables** | Variables defined directly within a playbook |
| **External Variable Files** | Variables stored in separate files |
| **Host Variables** | Variables applied to individual hosts |
| **Group Variables** | Variables applied to groups of hosts |
| **Variable Validation** | Checking variables to keep production automation reliable |
