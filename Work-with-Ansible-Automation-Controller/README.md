## 🔑 Key Concepts

| 🧠 Concept | 📝 Description |
|-----------|----------------|
| **Ansible Automation Controller** | Web-based interface for organizing, executing, and monitoring automation tasks |
| **Source Control Integration** | Git repository access and credentials configured in the Controller |
| **Project** | Automation content organized in the Controller |
| **Inventory** | Hosts targeted by automation jobs |
| **Job Template** | Reusable definition for running automation jobs |
| **Survey** | Collects input parameters for job execution |
| **Workflow Template** | Chains multiple automation tasks together |
| **Job Scheduling** | Automated, recurring execution of tasks |
| **Credential Management** | Secures access to resources used by automation |
| **Role-Based Access Control** | Controls who can do what within the Controller |
