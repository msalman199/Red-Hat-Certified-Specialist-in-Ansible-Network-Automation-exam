## 📖 Overview

In this lab, you learned how to view, monitor, and terminate processes on a Linux system using `ps`, `top`, and `kill`.

| 🎯 Focus Area | 📝 Description |
|--------------|----------------|
| **Process Viewing** | Analyzing running processes with `ps` options and filters |
| **Real-Time Monitoring** | Watching processes, CPU usage, and memory consumption with `top` |
| **Process Termination** | Using `kill` with different signals for graceful and forced termination |
| **Process Hierarchy** | Understanding parent-child relationships |
| **Performance Monitoring** | Identifying resource-intensive processes |

## 📚 Key Concepts

| 🔑 Concept | 📝 Description |
|-----------|----------------|
| **`ps`** | Views and analyzes running processes, with various options and filters |
| **`top`** | Real-time monitoring of system processes, CPU usage, and memory consumption |
| **`kill`** | Terminates processes using different signals |
| **Graceful Termination** | Ending a process with a signal that lets it shut down cleanly |
| **Forced Termination** | Ending a process with a signal that stops it immediately |
| **Process Hierarchy** | The parent-child relationships between processes in Linux |
| **Resource-Intensive Process** | A process consuming significant CPU or memory |
