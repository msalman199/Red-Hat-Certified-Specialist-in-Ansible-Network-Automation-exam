## 🔑 Key Concepts

| 📘 Concept | 📝 Description |
|-----------|----------------|
| **Repository** | The Git-tracked project holding your Ansible playbooks and their full change history |
| **Add / Commit / Push** | The core workflow for staging, recording, and publishing changes to a remote repository |
| **Branch** | An isolated line of development for working on features without affecting the main codebase |
| **Merge & Merge Conflict** | Combining branches, and resolving cases where changes overlap |
| **Clone & Remote** | Copying a repository and working with remote repositories for team collaboration |
| **Tag** | A marker used to label specific versions |
| **Git Stash** | Temporary storage of uncommitted changes |
