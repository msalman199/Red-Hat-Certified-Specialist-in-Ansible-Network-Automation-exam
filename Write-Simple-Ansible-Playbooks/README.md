## 🔑 Key Concepts

| 📘 Concept | 📝 Description |
|-----------|----------------|
| **Playbook** | A YAML file defining automation tasks, the foundation of infrastructure automation and configuration management |
| **`ansible-playbook` Options/Flags** | Command-line options used to control how playbooks are executed |
| **Variables** | Values used to parameterize playbooks, managed with best-practice organization |
| **Loops** | Repeating a task across multiple items |
| **Conditional Logic** | Running tasks only when specified conditions are met |
| **Error Handling & Recovery** | Mechanisms that let automation handle and recover from failures |
| **Templates** | Files used to generate dynamic configuration files |
